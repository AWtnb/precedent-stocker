# README

裁判所の判例検索サイト（courts.go.jp）から判例情報を定期的に取得し、スプレッドシートに蓄積するGoogle Apps Script。

## 概要

`MAIN_SHEET` のA列には、判例ページのURLに使われる番号（10000〜）が入っている。このスクリプトを数分おきに定期実行することで、1回の実行につき1行ずつ該当ページへアクセスし、判例情報（事件番号・事件名・裁判年月日・裁判所名）をB〜E列に埋めていく。

行数が数万件規模になる可能性があるため、スプレッドシート全体を読み込まず、`TextFinder` によるサーバー側検索を用いて未処理行を高速に特定する設計にしている。

## シート構成

### MAIN_SHEET（1枚目のシート）

ヘッダーなし。列の意味は以下の通り。

| 列 | 内容 |
|---|---|
| A | 判例番号（`https://www.courts.go.jp/hanrei/XXXXX/detail7/index.html` の `XXXXX` に該当）。あらかじめ10000〜の数値を入力しておく |
| B | 事件番号 |
| C | 事件名 |
| D | 裁判年月日 |
| E | 裁判所名 |

B〜E列は最初は空欄で、スクリプトの実行によって埋まっていく。**B〜E列は4項目すべて取得できた場合のみ書き込む**（一部だけ取得できても書き込まない）。

### LOG_SHEET（2枚目のシート）

A1セルのみ使用する。「次にMAIN_SHEETの何行目から探索を始めるか」を記録する。初回実行時は空欄扱いで、1行目（先頭）から探索する。

## 処理の流れ（`scrape`関数）

1. `LOG_SHEET` のA1を見て、探索を開始する行番号を決める（空欄なら1行目）
2. `MAIN_SHEET` のB列に対して `TextFinder` を使い、開始行以降で最初に見つかる**空白セルの行**を探す（＝A列しか埋まっていない未処理行）
3. 未処理行が見つかった場合
   - その行のA列の値（判例番号）を使い、`https://www.courts.go.jp/hanrei/XXXXX/detail7/index.html` にアクセスする
   - レスポンスが200の場合、HTML内から判例情報テーブルを解析する
     - ページ内に同種のテーブル（`module-sub-page-parts-table`）が複数存在する場合があるため、「事件番号」「事件名」「裁判年月日」「裁判所名」の4項目がすべて揃っているテーブルのみを対象とする
     - `dl`要素の出現順が不定だったり、一部の項目が欠落している場合があるため、`dt`のテキストをキーにして値を取得する（順序に依存しない）
     - 4項目すべて取得できた場合のみ、B〜E列に書き込む
   - 200以外（404など）の場合や、4項目が揃わなかった場合は何も書き込まない
   - 処理した行番号を `LOG_SHEET` のA1に記録する
     - 処理した行がシートの最終行だった場合、次回の開始行として1行目を記録する（＝先頭に戻る）
4. 未処理行が見つからなかった場合
   - 今回の探索が1行目から始まっていた（＝全行を1周確認した）場合のみ、`MAIL_TO` にメール通知する
   - 探索開始行が1行目以外だった場合は通知しない（まだ確認していない前半の行が残っている可能性があるため）

## 設計上のポイント

### 404は一時的なものとして扱う

判例番号によっては、その時点でページが未作成のため404になることがあるが、後日ページが作成されることがある。404の場合はB〜E列に何も書き込まないため、該当行は「未処理行」のままとなり、次回以降のループで自動的に再チェック対象になる。

### メール通知は「全行を1周確認できたとき」のみ送信

未処理行が見つからないケースには2種類ある。

- 探索開始行が1行目のとき：全行を確認した結果、本当に未処理行が存在しない
- 探索開始行が1行目以外のとき：まだ確認していない前半部分に未処理行が残っている可能性がある

後者で誤って「完了通知」を送らないよう、探索開始行が1行目だった場合に限ってメール通知する。

### パフォーマンス（TextFinderによる高速化）

行数が数万件になる可能性を考慮し、全データを `getValues()` で読み込む方式は採用していない。代わりに、B列のみを対象に `TextFinder`（正規表現 `^$` ＋完全一致）で空白セルを検索することで、検索処理自体をスプレッドシート側に任せ、Apps Script側への転送データ量を最小限に抑えている。

## 必要なスクリプトプロパティ

| キー | 内容 |
|---|---|
| `SHEET_ID` | 対象スプレッドシートのID |
| `MAIL_TO` | 完了通知の送信先メールアドレス |
